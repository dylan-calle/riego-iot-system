# riego-iot-system
Sistema inteligente de riego basado en IoT mediante ESP32, sensores de humedad del suelo y protocolo MQTT para la automatización y monitoreo del riego.

## Aplicación móvil

Para instalar las dependencias de Expo y ejecutar la app, entra primero en la carpeta `app`:

```bash
cd app
npm install
npx expo start
```

Es necesario instalar las dependencias antes de abrir el proyecto en VS Code para que TypeScript pueda resolver `expo/tsconfig.base` y `react-native`.
